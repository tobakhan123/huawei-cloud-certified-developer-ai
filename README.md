# 🚀 12 Weeks of AI & Machine Learning

Welcome to my **12-Week AI & Machine Learning Learning Journey!**

This repository contains 12 weeks of structured learning materials, practical exercises, notes, code examples, and projects covering Python programming, Machine Learning, Deep Learning, and Generative AI.

The purpose of this repository is to document my learning progress, strengthen my programming skills, and develop practical knowledge of Artificial Intelligence through hands-on experience.

## 🎯 Learning Objectives

- Build a strong foundation in Python programming.
- Understand essential data science libraries and tools.
- Learn Machine Learning concepts and algorithms.
- Explore Artificial Neural Networks and Deep Learning.
- Understand Natural Language Processing (NLP).
- Explore Hugging Face and pre-trained AI models.
- Develop practical AI and Machine Learning projects.
- Build a portfolio of hands-on work.

## 📚 12-Week Learning Roadmap

| Week | Topics | Learning Focus |
|------|--------|----------------|
| Week 01 | Python Fundamentals | Variables, data types, operators, conditions and loops |
| Week 02 | Python Advanced Concepts | Functions, lists, dictionaries, modules and file handling |
| Week 03 | NumPy & Pandas | Data manipulation and numerical computing |
| Week 04 | Data Visualization | Matplotlib, data analysis and visualization |
| Week 05 | Machine Learning Fundamentals | Introduction to ML, supervised and unsupervised learning |
| Week 06 | Regression Algorithms | Linear Regression and Multiple Linear Regression |
| Week 07 | Classification Algorithms | Classification, model training and evaluation |
| Week 08 | Deep Learning Fundamentals | Neural Networks, ANN and activation functions |
| Week 09 | Advanced Deep Learning | CNN and model optimization |
| Week 10 | Natural Language Processing | Text processing and NLP fundamentals |
| Week 11 | Hugging Face | Transformers, pretrained models and AI applications |
| Week 12 | Final Projects | Practical implementation and project development |
